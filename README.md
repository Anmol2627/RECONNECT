# RECONNECT

RECONNECT is a rehabilitation and reintegration platform.

## Tagline

Your journey. Our support. Stronger together.

## Goal

The goal is to help people move through their rehabilitation and reintegration journey by connecting them with:

- Personalized support
- Rehabilitation organizations
- Group sessions
- Peer communities
- Courses
- Programs
- Practical resources
- Progress tracking
- Facilitators/counselors

## Development

Run locally:
```sh
npm run dev
```

Build for production:
```sh
npm run build
```
